# kteam core redesign — caller-chosen names + first-class TASK titles

Scope owned: `modules/kteam-ts/src/**` and `kfleet/skills/rc-session/**`.
Peer `jessica` owns `ui/**` + `ui-dist/**` (untouched here).

## Flags & commands added

- `kteam start --teammate <name>` — use an exact caller-chosen callsign instead of
  auto-assigning one. Normalised to a slug `[a-z][a-z0-9-]*` (lowercased, trimmed,
  max 32 chars). Invalid input is **rejected loudly** (not rewritten). A collision
  with a LIVE session inside the 5-day `NAME_WINDOW_MS` window **fails loudly**,
  listing the conflicting `id (title)`.
- `kteam start --teammate-fallback` — escape hatch: on an invalid/taken name,
  auto-assign a free name instead of failing.
- `kteam name [-n/--count <k>] [--json]` — print up to `k` available name
  suggestions (default 1). Documented as a **suggestion, not a reservation**
  (TOCTOU: a later `start --teammate` can still collide). Exits non-zero if the
  daemon lookup fails.

When `--teammate` is absent the auto-assign path is unchanged.

## API / type changes

- `StartSessionRequest` (types.ts): added optional `teammate?: string` and
  `teammateFallback?: boolean`.
- `KTeamService` (service.ts): added `suggestNames(count?: number): Promise<string[]>`.
- HTTP: new `GET /v1/names?count=<k>` route (api-server.ts) → `suggestNames`.
  api-client.ts gained a matching `suggestNames()`.
- SessionManager (session-manager.ts):
  - `teammateNameUsage()` — `{recent, lastUsedAt, liveByName}` in one pass over the
    window; `liveByName` = non-terminal sessions per name.
  - `resolveTeammateName(request)` — auto-assign | normalise+collision-check |
    fallback. Called in `start()` right after the prompt-required check.
  - `suggestNames(count)` — up to 50 distinct free names via `pickTeammateName`.

## names.ts — the load-bearing fix (dixie blocker #1)

Old `sessionName()` slugified the title (`[^a-zA-Z0-9_-] → '-'`, cap 48), which made
the `[Teammate] Task Title` convention impossible (`[Hayden] Fix Transcript` →
`-hayden--fix-transcript`).

- Replaced with `displayName(raw)`: flattens control chars, collapses whitespace,
  trims, caps at 120 chars — **stores the human title verbatim** (brackets survive).
- The slug was never load-bearing: session dirs key on `id`, tmux on
  `shellSafeSessionName(id)`. Client idempotency (`findCreatedSession`) uses the
  same `displayName`, so matching stays consistent.
- Added `normalizeTeammateName(raw)` and `MAX_TEAMMATE_NAME_LENGTH = 32`.

TASK is now first-class: `config.name` holds the raw title and already surfaces in
`kteam ps` TASK column, `kteam status`, and the HTTP session view (jessica's
dashboard reads `config.name`). No bracket format is enforced — free-form names
still work.

## Skill changes

`kfleet/skills/rc-session/SKILL.md` rewritten:

- pick teammate name first via `kteam name`, Title-Case, compose
  `[<Teammate>] <Task Title>`, start with `--teammate` + `--name` in one shot.
- `--name` is the human TASK TITLE (verbatim), **not** the cwd basename (old, wrong).

- all prior rules kept: no injected prompt, default `claude-auto-kirin` + Opus 5,
  `--no-rc` opt-out, never ask about worktrees; Report block prints the title.
